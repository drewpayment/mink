# Incident Response Template

1. Declare — post in #incidents with severity and a one-line summary.
2. Stabilize — mitigate first, root-cause later.
3. Communicate — status updates every 30 minutes while active.
4. Write up — postmortem within 3 business days.

API Cache Outage — March 2026]].
