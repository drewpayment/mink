# Writing Style Guide

- Sentence case for headings, not Title Case.
- Prefer active voice.
- One idea per paragraph in docs; keep code blocks small and runnable.
- Commit messages: imperative mood, ("fix", not "fixed" or "fixes").

See also [[areas/code-review-standards|Code Review Standards]].
