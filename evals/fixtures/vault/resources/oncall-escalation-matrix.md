# On-call Escalation Matrix

If the primary on-call engineer doesn't acknowledge a page within 15
minutes, page the secondary. If the on-call engineer doesn't acknowledge
within 45 minutes total, escalate to the VP of Engineering.

Pairs with [[areas/oncall-rotation|On-call Rotation]] for who's currently
on the hook.
