# Deprecated v1 API Migration

The v1 REST API was sunset on 2026-01-15, three months after v2 (now
[[projects/orion-api/overview|Orion API]]) reached general availability.

All known v1 consumers were migrated ahead of the sunset date; no
exceptions were granted.
