# Legacy Monolith Notes

The original Rails monolith was decommissioned on 2025-11-30. Its
responsibilities were split: order/inventory/auth moved to
[[projects/orion-api/overview|Orion API]], and the storefront UI became
[[projects/atlas-web/overview|Atlas Web]].

Kept for historical reference only — do not resurrect patterns from here
without checking whether the split services already solved the problem
differently.
