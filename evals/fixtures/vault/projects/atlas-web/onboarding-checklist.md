# Atlas Web Onboarding Checklist

For new engineers joining the Atlas Web team:

1. Get repo access and run the local dev stack.
2. Read [[projects/atlas-web/overview|Atlas Web Overview]] and
   [[projects/atlas-web/design-system|Design System]].
3. Shadow a deploy.
4. Pair on a small ticket in your first week.
